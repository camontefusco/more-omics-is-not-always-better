# More Omics Is Not Always Better

## Provisional study title

**More Omics Is Not Always Better: A Pharmacology-Aware Evaluation of Multimodal Information Value for Cancer Drug-Response Prediction**

## Objective

Evaluate whether transcriptomic, mutation, and copy-number modalities provide drug- and mechanism-dependent incremental value for anticancer drug-response prediction, including cross-dataset reproducibility, missing-modality robustness, uncertainty, conflict, and clinically grounded evaluation.

## Submission target

*Information Fusion* Special Issue: “Trustworthy Multimodal Information Fusion for Healthcare: Representation, Causality, and Human-Centered Intelligence”

Deadline: 15 November 2026

## Reproducibility principles

- Keep raw data and credentials out of version control.
- Record dataset versions, download dates, preprocessing, splits, seeds, and software environments.
- Separate exploratory analyses from preregistered/confirmatory analyses.
- Treat the title and research question as provisional until the novelty check is complete.
