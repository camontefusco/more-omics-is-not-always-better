# Public-data access and licensing note

This project uses DepMap portal data releases for response and molecular features. The repository records dataset names, release identifiers, download provenance, and SHA-256 checksums in the manifest and ingestion documentation. Raw provider files are not redistributed here.

The portal states that data are available for community use and requests citation of the specific release, the DepMap portal, and the DepMap program. Dataset-specific download panels and release details control the applicable license and citation requirements; users must check those details for every file. See the [DepMap data page](https://depmap.org/portal/data_page/?tab=all) and the [DepMap license guidance](https://forum.depmap.org/t/license-for-data-found-in-the-depmap-portal/130).

Users reproducing the analysis should obtain the relevant files directly from the DepMap portal, review the portal terms of use and any dataset-specific restrictions, and confirm that their use is permitted for research and redistribution of derived summaries. The committed result tables contain derived performance metrics and metadata, not the raw molecular matrices.

The declared evaluation universe contains 15 prespecified compounds spanning GDSC1, GDSC2, and CTD². MoA mapping is complete for that declared universe; it is not a complete mapping of the full GDSC1 response universe.
