# Formal novelty-search protocol

## Scope

Search scholarly literature through August 2026 for work combining cancer drug-response prediction with multimodal/multi-omics fusion, modality contribution or ablation, missing-modality handling, uncertainty, mechanism-of-action stratification, and cross-dataset validation.

## Search concepts

- cancer drug response + multimodal / multi-omics / information fusion
- drug sensitivity + modality contribution / modality ablation / missing modality
- GDSC / CCLE / DepMap / CTRP / gCSI + multimodal or reproducibility
- drug response + mechanism of action / pharmacological class
- drug response + uncertainty / calibration / distribution shift
- FORGE, DrEval, and cross-study pharmacogenomic benchmark resources

## Evidence rules

- Prefer primary publications and official dataset papers.
- Verify title, authors, journal or preprint venue, year, and DOI/PMID when available.
- Record the exact source URL and verification date.
- Never infer missing bibliographic fields; mark them for manual verification.
- Do not finalize the novelty claim until the five strongest overlap papers have been assessed.

## Matrix

The working matrix will be stored as `docs/literature_matrix.csv` with one row per study and explicit fields for datasets, modalities, validation, ablation, missing modalities, mechanism-of-action stratification, uncertainty/calibration, cross-dataset validation, overlap, and remaining gap.
