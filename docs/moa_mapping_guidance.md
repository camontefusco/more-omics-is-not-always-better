# Mechanism-of-action mapping guidance

Each compound must retain its raw source identifier and receive an explicit mapping record. Use a curated source such as DrugBank, ChEMBL, DrugCentral, or an authoritative pharmacology publication, and record the source used for each assignment.

## Rules

- Prefer target- or pathway-based mechanism labels over broad therapeutic-area labels.
- Preserve multiple mechanisms when a drug is genuinely multi-target; designate one primary label only when justified.
- Mark compounds with ambiguous, context-dependent, or insufficiently documented mechanisms as `uncertain`.
- Do not infer mechanism from model performance or response patterns.
- Predefine minimum stratum sizes before calculating mechanism-specific estimates.
- Keep a mapping version and audit date.
